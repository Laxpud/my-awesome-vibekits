# 目录 README

默认由技术文档承担系统、组件和源码关系，不为每个源码目录生成 README。

保留独立 README 的合理情况：

- 目录是独立使用的包、工具或可分发子项目，确有自己的用户入口。
- 就地必须看见的生成规则、安全约束或操作条件不能只藏在远处。

普通源码目录的关系说明在组件页的图和源码映射中表达；目录 README 如仍有导航价值，短链接到技术页即可，不维护第二份架构。已有重复说明只在明确整理范围内合并，不借普通实现任务删除全部目录 README。

覆盖自有生产代码和关键脚本可以使用分组表或多个小图，不要求每个辅助文件都有长段落。关系图回答协作或依赖，目录树回答位置，两者不要混淆。
