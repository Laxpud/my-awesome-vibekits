# 组织规划文档

仅在用户显式调用本技能时使用。读取[共同写作约定](../project-docs-progress/references/writing-style.md)，根据请求读取现有规划入口和相关条目；不为一次规划调整通读整个仓库。

| 当前任务 | 按需读取 |
| --- | --- |
| 建立或调整 TODO、roadmap、milestone、backlog | [职责与格式](references/planning-model.md)、[具体模板](assets/planning-templates.md) |
| 保存或链接 plan/spec、切换阶段、归档、处理暂停与取消 | [生命周期](references/lifecycle.md) |

把未来方向、当前承诺与已完成记录分开。沿用清晰的既有路径；只有新建或已授权迁移时采用默认布局。模板固定信息位置，不规定唯一的执行步骤，也不强制每个任务产生方案或证据。

Agent 自行生成 plan/spec。本技能只管理保存、链接和归档，不规定其正文结构，也不要求重写、补全、持续维护或另产 current-plan。

普通任务勾选由轻量进度维护即可，不是重新规划的理由。调整承诺、阶段顺序和旧历史范围时服从用户指令；没有充分依据不擅改原方案。结束时说明实际调整和未决事项，不另建规划审计报告。
