# 保存、切换与归档

只处理本次变化涉及的条目和材料；日常勾选无需执行完整生命周期。

## 保存 plan/spec

Agent 决定 plan/spec 的正文结构；本插件不要求生成、补全、润色、复核或持续维护其内容。临时材料可留在 agent 原生位置。作为长期 TODO 或 roadmap 依据时，保存到项目可持续访问的位置，不假设其他机器或会话能访问原生路径。

默认分别保存到 `docs/plans/` 和 `docs/specs/`，采用创建时间命名：`plan-YYYY-MM-DD-HH-mm.md`、`spec-YYYY-MM-DD-HH-mm.md`。已有清晰路径可沿用；同一分钟冲突用 `-2` 等后缀区分，不覆盖。保护 agent 仍在使用的原文件，保留必要附件，不反复导入同一份内容。

在所属任务或里程碑链接材料。未来方案保留到实施时，届时核对实施前提；前提仍成立就沿原思路推进，变化实质影响结果时说明差异。管理文档不等于获准修改方案正文或代码。

## 切换当前里程碑

只有用户授权推进时，才将选定未来里程碑从 roadmap 移入 TODO；原处缩为当前入口链接，不复制第二份任务状态。TODO 的下一个里程碑只有名字与 roadmap 链接，没有下一项就省略。

## 完成归档

任务勾选不代替里程碑目标与完成条件。目标满足且未完成事项有明确去向后：

- 将 TODO 的原里程碑区块直接剪切到 `docs/archive/milestone-YYYY-MM-DD-HH-mm-title.md`。时间为完成归档时间，精确到分钟；不覆盖同名文件。
- 相关工作全部结束的 plan/spec 原文移入同一 archive，保留原文件名。共享材料等所有关联工作结束后再移。
- 机械修正移动材料、附件与所有受影响引用的相对路径，包括 Markdown 引用式链接和 HTML 链接；历史任务保留 plan/spec 链接。不要为修链接重写正文。
- Roadmap 已完成列表增加名称与链接；更新 TODO 活动入口。没有下一阶段授权时保持“当前无进行中的里程碑”，不自动开始下一阶段。

不重写归档内容，不新增验收报告、历史摘要或归档时的全面提炼。长期有效的约定应在实施或计划内文档节点更新到技术文档；若归档时发现遗漏，只处理确实缺失的必要约定，不重加工全部历史。

## 未完成与异常

暂停：保留未完成项、方案和必要恢复条件，不按完成归档。
取消：明确标注“已取消”和一句原因，不用勾选伪装完成。
终止整个里程碑：可保存原清单，roadmap 单列“已终止”，不混入已完成列表；归档正文明确终止状态。
拆分或延期：未完成事项移到明确的新任务、未来里程碑或 Backlog，保留必要去向，不丢失约束和证据。

## 必要证据

只有用户要求或后续判断、测量、复现依赖的材料才保存到 `docs/evidence/`。已有合适持久来源就链接，不在 TODO、output、docs 复制多份。真实模型、测量数据和测试产物可以保留，不因此自动编写 Markdown 总结。重要证据不因任务结束自动删除。
