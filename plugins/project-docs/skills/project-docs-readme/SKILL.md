# README 与使用说明

仅在用户显式调用本技能时使用。读取[共同写作约定](references/common/writing-style.md)。面向不熟悉仓库、代码经验较少的预期用户，用可执行的操作和可观察的结果说明用法。

| 当前任务 | 按需读取 |
| --- | --- |
| 创建、审查或修改 README / 正式翻译 | [README 约定](references/readme-contract.md)、[README 模板](assets/readme-template.md) |
| 编写日常用法、选项、使用问题说明 | [使用说明约定与模板](references/usage-guide.md) |

按请求读取现有入口和支持相关声明的代码、配置或发行资料，不通读所有文档。项目获取方式依实际发行版、插件市场、包管理器或源码路径选择，不套用固定安装命令。

用户只要求审查则保持只读；已授权修改直接执行，不再默认提交审计等待确认。只有读者、定位或推荐路径等关键歧义才询问。更新受影响的公共事实与正式翻译；不借 README 工作重构全部技术文档。

在里程碑或发布节点核对变化；直接阻碍使用的失效说明及时修正。按条件核实改动的链接、命令和操作，不能执行的不声称已通过；不另产文案审计或验收报告。
