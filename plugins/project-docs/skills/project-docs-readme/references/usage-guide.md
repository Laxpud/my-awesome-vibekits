# 使用说明

只有快速开始之后仍有值得独立说明的日常任务时才建立，默认 `docs/usage.md`。简单项目可在 README 中说清，不为了结构完整造文档。

按用户要完成的事组织，而不是按内部模块或全部 CLI 参数组织。每项写清前提或输入、操作、结果；UI、命令或配置按项目实际选择。常用选项解释用途、默认值和改变后的影响，不倾倒完整命令帮助。故障按可见现象写排查动作，深入机理链接技术文档。

不重复 README 安装过程，不放开发环境安装教程、实现过程或历史日志。独立主题确实较多时拆页并保持一个入口；每页链接回入口，相关任务按需要互链。

## 示例模板

```markdown
# 使用说明

适用范围：本说明已核对的版本或里程碑。

开始前请先完成[快速开始][start]。

## 批量导出文件

准备：一个包含待处理文件的目录。
操作：选择输入目录并执行“批量导出”。
结果：输出目录出现成功文件；失败项显示原因，其他项继续执行。

### 常用选项

| 选项 | 用途 | 默认值 | 调整后的影响 |
| --- | --- | --- | --- |
| 输出目录 | 保存导出结果 | 项目实际默认位置 | 改变文件保存位置 |

## 找不到输出文件

先查看界面显示的输出目录，再检查是否有失败提示。
```
